#Simulador de Investimentos

##Descrição
Aplicativo desenvolvido em Flutter para simular investimentos mensais. O usuário informa o valor mensal, o número de meses e a taxa de juros mensal. O app calcula o valor acumulado com e sem juros compostos.

##Funcionalidades
- Inserir valor mensal
- Inserir quantidade de meses
- Inserir taxa de juros (%)
- Calcular valor total sem juros
- Calcular valor total com juros compostos

##Fórmulas utilizadas
Sem juros = valor mensal × meses  
Com juros compostos = cálculo acumulativo mensal

##Tecnologias
- Flutter
- Dart

##Como executar
1. Clone o repositório:
git clone https://github.com/CorreaLeticia/Flutter-Investimento.git

2. Abra no VSCode ou Android Studio

3. Execute:
flutter pub get
flutter run
